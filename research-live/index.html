02

每轮相对父版的变化

已采用 / 候选未采用 / 父版

64 道验证题，父版和候选各独立运行 3 次（各 192 次尝试）。Mean@3 是三次正确率的平均，不是任一次成功就算通过。每轮均与当时保留的父版比较；各轮改善不能相加为累计提升。

采用门槛：未四舍五入的平均改善严格超过 1 个百分点。95% 配对 bootstrap 区间和重复间标准差只作说明，区间跨过 0 时不能称为统计显著提升。
